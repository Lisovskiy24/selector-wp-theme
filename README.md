# Selector Landing — тема WordPress

Классическая PHP-тема для лендинга-обзора онлайн-казино Selector. Вёрстка вручную, без фреймворков,
jQuery и плагинов; стили по собственному UI-киту в Figma.

- Демо на WordPress: http://lisovsy1.beget.tech
- Статичная версия (HTML/CSS/JS): https://lisovskiy24.github.io/selector-landing/ · [код](https://github.com/Lisovskiy24/selector-landing)

## Установка

1. Скачать архив репозитория (Code → Download ZIP) или склонировать в `wp-content/themes/selector`.
2. «Внешний вид → Темы → Добавить → Загрузить тему» → выбрать архив → «Установить» → «Активировать».
3. «Настройки → Постоянные ссылки» → «Название записи» → «Сохранить» (для ссылок `/go/selector/`).

Подробнее — в [readme.txt](readme.txt).

## Что умеет

- **Настройки оффера** без правки кода: «Внешний вид → Настроить → Оффер» — бренд, промокод, бонус, вейджер,
  мин. депозит, кэшбэк, партнёрская ссылка, автор и дата обзора. Значения подставляются во все блоки.
- **Раздел «Игры»** в админке (свой тип записей): обложка, провайдер, рейтинг, метка «Эксклюзив».
  Пока игр нет — на главной показываются категории.
- **Партнёрские ссылки** `/go/{slug}/` → 302-редирект на ссылку из настроек, `X-Robots-Tag: noindex`; без ссылки — заглушка.
- **Свой текст обзора**: если у страницы, назначенной главной, есть содержимое — оно заменяет обзор по умолчанию
  (таблицы, списки и цитаты из редактора блоков оформлены в стиле темы).
- **SEO**: meta description (если нет Yoast / Rank Math), разметка Schema.org `Review` и `FAQPage`.

## Технические решения

- Mobile-first, BEM, дизайн-токены в CSS-переменных; Flexbox для простых раскладок, Grid для сеток; `<table>` — только для данных.
- Семантика: `header`, `main`, `section`, `article`, `aside`, `nav`, `footer`; FAQ на `<details>` — работает без JavaScript.
- JS ~4 КБ без зависимостей: меню, копирование промокода, липкая панель (IntersectionObserver), лайтбокс на `<dialog>`.
- Скорость: локальные woff2-подмножества шрифтов, WebP с `srcset` и явными размерами, `preload` шрифта и первого баннера,
  `defer` для скрипта, отключены эмодзи-скрипты и лишнее из `<head>`, версии файлов по времени изменения.
- Безопасность: всё экранируется (`esc_html`, `esc_attr`, `esc_url`, `wp_kses`), nonce и проверка прав при сохранении полей игры.

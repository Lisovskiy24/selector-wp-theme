=== Selector Landing ===

Тема-лендинг для обзора онлайн-казино. Вёрстка без фреймворков, стили по UI-киту из Figma.

== Установка ==

1. «Внешний вид → Темы → Добавить → Загрузить тему» → выбрать selector-theme.zip → «Установить» → «Активировать».
2. «Настройки → Постоянные ссылки» → выбрать «Название записи» → «Сохранить» (нужно для ссылок /go/selector/).
3. Главная страница выводится шаблоном front-page.php сразу после активации.

== Что редактируется в админке ==

* «Внешний вид → Настроить → Оффер» — название казино, промокод, бонус, вейджер, минимальный депозит,
  подзаголовок, кэшбэк, количество игр, партнёрская ссылка, автор и дата обновления обзора. Значения подставляются
  в оффер, карточки бонусов, сайдбар, шаги, таблицу, FAQ и подпись обзора.
* «Игры» — карточки в блоке «Популярные игры»: название, изображение записи (3:4), провайдер, рейтинг, метка «Эксклюзив».
  Порядок задаётся полем «Порядок». Пока игр нет, показываются категории (слоты, live-казино, быстрые игры, спорт).
* Оценка редакции (баллы по критериям) задаётся в template-parts/review-default.php, итог считается как среднее.
  Для обзора и FAQ выводится разметка Schema.org (Review, FAQPage).
* «Внешний вид → Меню» — меню «В шапке» и «В подвале». Без меню выводятся якоря по секциям.
* Текст обзора: «Настройки → Чтение → Статическая страница» и выбрать страницу. Если у неё есть содержимое,
  оно заменит обзор по умолчанию (таблицы и списки из редактора блоков уже оформлены в стиле темы).

== Партнёрские ссылки ==

Все кнопки ведут на /go/selector/. Тема отдаёт 302-редирект на ссылку из настройки «Партнёрская ссылка»
с заголовком X-Robots-Tag: noindex. Если ссылка не задана — показывается страница-заглушка.

== Структура ==

style.css            — заголовок темы
functions.php        — подключение модулей, меню, стили и скрипты
header.php / footer.php
front-page.php       — лендинг из секций template-parts/
singular.php         — страницы и записи
index.php            — архивы, поиск, 404
inc/helpers.php      — sel_opt(), sel_icon(), sel_img(), sel_go_url()
inc/customizer.php   — настройки оффера
inc/games.php        — тип записей «Игры»
inc/redirect.php     — /go/{slug}/
inc/performance.php  — чистка <head>, preload шрифта и первой картинки
inc/seo.php          — meta description, если нет Yoast / Rank Math
template-parts/      — секции: offer, bonuses, games, vip, review-default, sidebar, faq, sprite, nav-default, go-stub
assets/              — css, js, шрифты (woff2), картинки (webp)
